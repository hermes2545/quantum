## A-01 — เมนูส่วนท้าย: PDF ต้นฉบับสำหรับอ้างอิง

**สั่งโดยผู้ใช้:** 5 ก.ย. 2026

### สิ่งที่ต้องการ
เพิ่มเมนูส่วนท้ายของเว็บ ให้เข้าถึง **PDF ต้นฉบับทั้ง 9 เล่ม** ได้ เพื่อใช้เป็น reference
อ้างอิงกลับไปยังหนังสือจริง

### สถานะลิขสิทธิ์ — ได้รับอนุญาตแล้ว
**ผู้ใช้ยืนยัน 5 ก.ย. 2026: ได้รับอนุญาตจากผู้เขียนเรียบร้อยแล้ว**
จึงเปิดให้เข้าถึง PDF ต้นฉบับได้ โดยมี **เงื่อนไขบังคับ: ต้องอ้างอิงชื่อผู้เขียนต้นฉบับ**

### ความสัมพันธ์กับ spec หลัก §11 ข้อห้าม #2
ใบสั่งงานหลักเขียนว่า *"ห้ามเสิร์ฟหรือ commit PDF ต้นฉบับ"* ด้วยเหตุผลลิขสิทธิ์
เมื่อได้รับอนุญาตแล้ว ข้อห้ามนี้ถูกแก้ดังนี้:

1. **"ห้ามเสิร์ฟ" — ยกเลิก** เสิร์ฟได้ทั้งเฟส 1 และเฟส 2
2. **"ห้าม commit" — ยังคงอยู่** PDF อยู่ใน `content/source/` ที่ gitignored
   (เหตุผลเปลี่ยนจากลิขสิทธิ์เป็นเรื่องขนาดไฟล์ ~52 MB ไม่ควรอยู่ใน git)
3. **การอ้างอิงผู้เขียนเป็นข้อบังคับ** ไม่ใช่ตัวเลือก — ดูหัวข้อ "การให้เครดิต" ด้านล่าง
4. ข้อห้ามเดิมเรื่อง **ห้ามคัดลอกข้อความจากหนังสือลงเนื้อหาบท (§9.1 ข้อ 1)
   ยังมีผลเต็มที่** — การอนุญาตนี้ครอบคลุมการ "เปิดให้อ่านต้นฉบับ"
   ไม่ได้เปลี่ยนหลักการว่าคู่มืออธิบายด้วยคำของเราเอง

### การให้เครดิตผู้เขียน (บังคับ)
**ผู้เขียน: สิรวิชญ์ รัตน์จินดา**

ต้องปรากฏในทุกจุดต่อไปนี้:
- `SourceFooter` ทุกหน้า — "หนังสือชุดโดย สิรวิชญ์ รัตน์จินดา · เผยแพร่ต้นฉบับโดยได้รับอนุญาตจากผู้เขียน"
- หน้าชั้นหนังสือ (`/`) — เครดิตผู้เขียนใต้หัวเรื่องชุด
- หน้าแผนที่เล่ม (`/b/{book}`) — บรรทัดผู้เขียนใต้ชื่อเล่ม (field `Book.author` ที่มีอยู่แล้ว)
- `ChapterRail` footer — ตามที่ prototype ทำไว้แล้ว
- `README.md` ของ repo

### Component ใหม่: `SourceFooter`

**ตำแหน่ง:** ท้ายทุกหน้า — ชั้นหนังสือ (`/`), แผนที่เล่ม (`/b/{book}`),
บทเรียน (`/b/{book}/{ch}`), หน้าศัพท์รวม (`/glossary`)

**บนหน้าบทเรียน:** วางถัดจาก `ChapterNav` และอยู่ **เหนือ** padding-bottom 120px
ที่กันไม่ให้ FAB ทับ (§5 กฎข้อ 7) — FAB ต้องไม่ทับเมนูนี้

**หน้าตา:**
- หัวข้อเล็ก: "ต้นฉบับอ้างอิง"
- บรรทัดเครดิตผู้เขียน: "หนังสือชุดโดย สิรวิชญ์ รัตน์จินดา"
- รายการ 9 เล่ม เรียงตาม `order` แต่ละรายการ = ชื่อเล่ม + ขนาดไฟล์
- **เล่มที่กำลังอ่านอยู่ ขึ้นก่อนและเน้น** (บนหน้าบท/แผนที่เล่ม)
- ประโยคกำกับ: "เปิดเพื่ออ่านต้นฉบับ — คู่มือนี้อธิบายด้วยคำของเราเอง ไม่ใช่ข้อความจากหนังสือ"
- บรรทัดเครดิต (บังคับ): "หนังสือชุดโดย สิรวิชญ์ รัตน์จินดา · เผยแพร่ต้นฉบับโดยได้รับอนุญาตจากผู้เขียน"

**พฤติกรรม:**
- กด → เปิด PDF ใน tab ใหม่ (`target="_blank" rel="noopener"`)
- ไม่ต้อง preload / ไม่ต้องเรียก API ตอนโหลดหน้า (§11 ข้อห้าม #7)
- รายการเล่มอ่านจาก `index.json` ที่มีอยู่แล้ว ไม่ต้อง fetch เพิ่ม

### Mobile (บังคับตาม §5)
- รายการเป็น **1 คอลัมน์เสมอ** ที่ `≤ 860px`
- แต่ละรายการ hit area `≥ 44px` สูง
- ชื่อเล่มยาว → `word-break` ได้ **ห้ามทำให้ body scroll แนวนอน**
- ฟอนต์ `≥ 15px` (เล็กกว่า body ได้เพราะเป็น footer แต่ห้ามต่ำกว่านี้)

### สี (ตาม §4 — ห้าม hard-code)
- พื้น `--paper-2`, เส้นคั่นบน `--line`, ตัวอักษร `--ink-2`,
  ชื่อเล่ม `--ink`, ลิงก์ hover `--gold`
- **ใช้ทอง** เพราะเป็นฝั่งหนังสือ/ธรรมะ ไม่ใช่เขียวน้ำทะเล (ฝั่งวิทยาศาสตร์/ผู้ช่วย)

### Data model — เพิ่มใน `Book`
```
sourcePdf?: {
  file: string      // ชื่อไฟล์ใน content/source/ เช่น "1.1 E-book ไตรลักษณ์ในควอนตัม ....pdf"
  bytes: number     // ขนาด ใช้แสดงในเมนู
}
```
`index.json` เพิ่ม `sourcePdf` ต่อเล่ม (เฉพาะ `file` กับ `bytes` ไม่ต้องใส่ path เต็ม)

### Proxy — endpoint ใหม่
```
GET /api/source/{bookSlug}.pdf
```
- map `bookSlug` → ชื่อไฟล์จาก `book.json` **ห้ามรับ path จาก client ตรงๆ**
  (กัน path traversal) — เทียบกับ allowlist ที่ build มาจาก `index.json` เท่านั้น
- ตอบ `Content-Type: application/pdf`,
  `Content-Disposition: inline; filename="..."`,
  `Cache-Control: private, max-age=3600`
- **ไม่นับรวมใน rate limit ของ §9.5** (คนละเรื่องกับค่า API)
- log แค่ `timestamp, bookSlug, bytes` ตามแนว §9.5

**ข้อควรระวังเฟส 2:** §11 กำหนดให้ proxy ย้ายไป Cloudflare Pages Functions และ
**ห้ามผูกกับ Node API เฉพาะเช่น `fs`** — endpoint นี้จึงต้องอ่านไฟล์ผ่าน
adapter ที่สลับได้ (`fs` บนบ้าน / R2 หรือ static asset binding บน Cloudflare)
ไม่ใช่เรียก `fs.readFile` ตรงๆ ในตัว handler
