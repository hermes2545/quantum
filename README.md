# ไตรลักษณ์ในควอนตัม — คู่มือเดินทางแบบโต้ตอบ

หนังสือชุดโดย **สิรวิชญ์ รัตน์จินดา** · เผยแพร่ต้นฉบับโดยได้รับอนุญาตจากผู้เขียน

แพลตฟอร์มเรียนรู้หนังสือชุดธรรมะ-วิทยาศาสตร์ 9 เล่มสำหรับคนทั่วไปที่ไม่มีพื้นฐาน สามารถถามผู้ช่วย AI ได้ทุกจุด เรียนรู้ด้วยภาพเคลื่อนไหวโต้ตอบ และอ้างอิงต้นฉบับได้

## ตั้งค่าอย่างรวดเร็ว (Quick Start)

### ข้อกำหนดเบื้องต้น

- **Docker** + **Docker Compose** v2+
- **Node.js 20+** (สำหรับ build)
- **Python 3.11+** (สำหรับ pipeline; ตัวเลือก)
- **Ubuntu/macOS** (ทดสอบบน Ubuntu 22.04 และ macOS 13+)
- **Tailscale** สำหรับการเข้าถึง (เฟส 1 ไม่เปิด port สาธารณะ)

### 1. Clone และสร้าง environment

```bash
git clone <repo-url> dhamma-science-learning
cd dhamma-science-learning

# สร้าง .env จากตัวอย่าง
cp .env.example .env
```

### 2. ตั้ง API key

แก้ไข `.env` และใส่ ANTHROPIC_API_KEY:

```bash
# .env
ANTHROPIC_API_KEY=sk-ant-...
MODEL=claude-opus-5
PORT=8787
RATE_DAY=30
RATE_MIN=5
SERVE_SOURCE_PDF=true
AUTHOR_MODEL=claude-fable-5-1
```

### 3. วางไฟล์ PDF ต้นฉบับ (เฟส 1 = เล่มแรกเท่านั้น)

```bash
# สร้างโฟลเดอร์สำหรับ PDF ถ้ายังไม่มี
mkdir -p content/source

# วาง PDF ต้นฉบับลงตรงนี้ (ไม่ commit ลง git)
# เช่น: content/source/1.1 E-book ไตรลักษณ์ในควอนตัม ....pdf
```

จากนั้น อัปเดต `content/books/trilaksana-quantum/book.json` เพื่อให้ตรงกับชื่อไฟล์:

```json
{
  "slug": "trilaksana-quantum",
  "sourcePdf": {
    "file": "1.1 E-book ไตรลักษณ์ในควอนตัม ....pdf",
    "bytes": 52428800
  }
}
```

### 4. รัน pipeline (ตัวเลือก — เฉพาะถ้าต้องการสร้างเนื้อหาบทใหม่)

```bash
# ติดตั้ง Python dependencies
cd pipeline
pip install -r requirements.txt
cd ..

# Extract → Clean → Split → Author → Terms
make pipeline STEP=extract BOOK=trilaksana-quantum
make pipeline STEP=clean BOOK=trilaksana-quantum
make pipeline STEP=split BOOK=trilaksana-quantum
# ... ตามวิธีต่างๆ ดูใน Makefile
```

### 5. Build และรัน

```bash
# Build static site และรัน Docker
make up
```

ระบบจะ:
1. เรียก `node web/build.js` (validate + render HTML + copy assets)
2. สร้าง Docker images
3. เปิด port 8080 (Caddy reverse proxy)

### 6. เข้าถึงผ่าน Tailscale

หลังจาก `make up` สำเร็จ:

```bash
# ใช้ tailscale hostname (หรือ IP Tailscale)
open http://<tailscale-hostname>:8080
```

ทดสอบว่า:
- โฮมเพจแสดงบท 9 บท
- บทที่ 1–2 อ่านได้ (ถาม, ทำแบบฝึก)
- บทที่ 3–9 แสดง "กำลังสร้าง"
- ถามได้ทั้ง 30 คำถาม/วัน

## Makefile targets

```bash
make build          # build.js validate + render static site
make up             # make build + docker compose up -d --build
make down           # docker compose down
make logs           # docker compose logs -f
make validate       # ตรวจสอบ JSON schema ทั้งหมด

# Pipeline
make pipeline STEP=extract BOOK=trilaksana-quantum
make pipeline STEP=clean BOOK=trilaksana-quantum
make pipeline STEP=split BOOK=trilaksana-quantum
make pipeline STEP=author BOOK=trilaksana-quantum CH=ch03
make pipeline STEP=terms BOOK=trilaksana-quantum

# Health check
make check          # curl /api/health + grep -r "sk-ant" + ตรวจ PDF
```

## การประเมิน (Checklist เฟส 1)

ตรวจสอบว่า:

- [ ] `docker compose up` รันบน Ubuntu แล้วเข้าถึงได้จากมือถือผ่าน Tailscale (iOS/Android)
- [ ] ผ่าน mobile responsive ทั้ง 360/390/768/1280px
- [ ] บท 1–2 ตรงกับ prototype ทั้งข้อความ, ศัพท์, interactive, exercise, questions
- [ ] บท 3–9 ตรงตาม gฎ §9.1 ทั้ง 11 ข้อ และผ่านคนตรวจแล้ว
- [ ] ถามผู้ช่วย 10 คำถาม (จาก `.questions`) — คำตอบอ้างเล่ม/บท ไม่มี bullet ≤ 8 ประโยค
- [ ] Rate limit ทำงาน (คำถามที่ 31 / (วัน) หรือ 6 / (นาที) ได้ 429)
- [ ] ปิดเบราว์เซอร์ → เปิดใหม่ → เด้งไปบทล่าสุด + ✓ "อ่านจบ" ถูกต้อง
- [ ] `grep -r "sk-ant" web/ content/` ไม่พบ (ไม่มี API key ใน code)
- [ ] `git status` ไม่มี PDF (ยังอยู่ใน content/source/ gitignored)
- [ ] SourceFooter ปรากฏทั้ง 4 หน้า (/, /b/x, /b/x/ch, /glossary)
- [ ] เครดิต "สิรวิชญ์ รัตน์จินดา" ปรากฏครบ 5 จุด (README + 4 หน้า)
- [ ] เปิด PDF ได้จริงจากมือถือ iOS/Android

## ข้อเตือน: ตั้งค่า Spend Limit

**สำคัญมาก:** Anthropic API คิดค่า per token. ตั้ง spend limit เพื่อป้องกันค่าใช้จ่ายเกิน:

1. เข้า [console.anthropic.com](https://console.anthropic.com)
2. Settings → Usage Limits
3. ตั้ง Daily Budget เป็น ~$10–20 ต่อวัน (สำหรับเฟส 1 ปกติ ≤ $1/วัน)

หลังจบเฟส 1 ถ้าต้องการ production ให้ขอ higher limits

## ความเป็นส่วนตัว + Logging

- **ไม่บันทึก content ของคำถาม** — บันทึกเฉพาะ `timestamp, bookSlug, chapterSlug, tokens, latency` (§9.5)
- **ไม่ส่งข้อมูลไปให้บุคคลที่สาม** — Anthropic API ตามนโยบายของพวกเขา
- **localStorage เก็บ locally** — ความคืบหน้านอน ประวัติแชท บนเบราว์เซอร์ผู้ใช้เท่านั้น
- **ไม่มี cookies / session / server-side state** ในเฟส 1

## การเรียบเรียงเนื้อหา

บทที่ 1–2 ของเล่มแรก **คัดลอกตรงจาก prototype** ไม่มีการเปลี่ยนแปลง

บทที่ 3–9 (และเล่มอื่นในเฟส 2) ต้องปฏิบัติตาม 11 กฎของ §9.1:

1. ห้ามคัดลอกข้อความจากหนังสือยกเว้นพุทธพจน์/วลีสั้น
2. โครงบท: goal → sections → interactive → quote → exercise → questions
3. ศัพท์เทคนิคต้องอธิบายครั้งแรกเลย
4. ทุก section ต้องโยงกลับไตรลักษณ์
5. มี "ข้อผิดพลาดที่คนเข้าใจผิด" ≥ 1 จุด
6. ตัวเลขวิทย์ใช้ค่าปัจจุบัน
7. เรื่องที่วิทยาศาสตร์ยังถกเถียงต้องระบุว่า "สมมติฐาน"
8. ไม่มี bullet ในเนื้อหา เฉพาะรายการธาตุ/ชนิด
9. ความยาว 900–1,400 คำต่อบท
10. `exercise` 4 ตัวเลือก × 3 ขั้น ตัวอย่างใกล้ตัวคนไทย
11. `questions` 4 ข้อต้องเป็นคำถามจริงที่คนสงสัย ไม่ใช่ท่องจำ

```bash

  "bookSlug": "trilaksana-quantum",

  "bookSlug": "trilaksana-quantum",
  "chapterSlug": "ch01",
  "option": "รถยนต์",

# ดาวน์โหลด PDF (A-01)
GET /api/source/{bookSlug}.pdf
# Response: 200 application/pdf (inline in browser)
```

## Troubleshooting

### ไม่มี internet เข้า Tailscale
- ตรวจสอบว่า Tailscale agent กำลังรัน: `tailscale status`
- ให้ ubuntu/localhost เข้า internet: ตรวจสอบ router + firewall

### API key ไม่ใช้ได้ (503 "ระบบยังไม่ได้ตั้งค่า")
- ตรวจสอบ `.env` มี `ANTHROPIC_API_KEY` ไม่ว่างเปล่า
- `docker compose logs proxy` — มี error gì?

### คำตอบผู้ช่วยไม่ขึ้น / "กำลังคิด…" ค้าง
- ตรวจสอบ `docker compose logs proxy` มี error หรือ timeout
- ลองถาม shorter question (< 1000 chars)
- ตรวจสอบ spend limit ใน Anthropic Console

### Mobile responsive ไม่ทำงาน
- ใช้ `make validate` ตรวจสอบ CSS media queries
- เปิด DevTools → Device emulation → iPhone/Android resolution

### SourceFooter ไม่ขึ้น / PDF ไม่เปิด
- ตรวจสอบ `content/books/trilaksana-quantum/book.json` มี `sourcePdf.file` ชื่อตรงกับไฟล์จริง
- ตรวจสอบ `SERVE_SOURCE_PDF=true` ใน `.env`
- เรียก `make build` สร้าง `content/index.json` ใหม่
